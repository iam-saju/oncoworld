# OncoWorld reports

Generated by `scripts/make_reports.py` (needs reportlab). Regenerate after any change in `cases_src/`, so the PDFs
match the repo; grader results and oracle numbers are recomputed each run.

| File | Audience | Contents |
|---|---|---|
| `oncoworld_phase2_final_analysis.pdf` | project team, reviewers | v1 assessment, what Phase 2 changed, results (v1 gold vs v2 rubric, oracle runs), case-by-case analysis, journey, grader limits, next steps |
| `cases/<case>_v2_case_pack.pdf` (x5) | reviewing oncologist | CONFIDENTIAL: task instruction, full model-visible chart, reference answer, rubric, self-test results, sign-off box |
| `cases/dlbcl_0003_journey_v2_case_pack.pdf` | reviewing oncologist | CONFIDENTIAL: layers 2-5 documents, questions, draft reference answers and rubrics |

The case packs contain answer keys. Never place them where an evaluated model can read them (task images,
prompts, public uploads).
